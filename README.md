# 🛒 R BD SHOP — Full Production E-Commerce Platform

**R BD SHOP** হলো একটি সম্পূর্ণ production-ready, dynamic, scalable e-commerce platform।
Admin Panel থেকে Product Add/Edit/Delete করলে তা সরাসরি Firebase-এর মাধ্যমে Customer Website-এ রিয়েল-টাইমে প্রতিফলিত হয়।

---

## 🚀 Technology Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES Modules)
- **Backend/DB:** Firebase (Auth + Firestore + Storage)
- **Hosting:** Render (Static Sites) + GitHub
